### Course Overview  
**Course Code:** DES503  
**Course Name:** Introduction to 3D Character Animation  
**Credits:** 4  
**Offered To:** Undergraduate/Postgraduate (UG/PG)  
**Course Description:** This course introduces students to the fundamentals of animation, focusing on character animation and its application in creating engaging stories. It covers the basics of animation principles, workflow, and advanced techniques using Maya software. Students will learn how to design characters, create animations, and integrate them into complete projects.  

**Prerequisites (Mandatory):** None specified.  
**Desirable Prerequisites:** Introduction to Motion Graphics (DES518) or equivalent experience with animation tools is recommended but not mandatory.  

---

### Learning Outcomes (COs)  
By the end of this course, students will be able to:  
- **CO1:** Understand and explain the basic principles of animation workflow and character modeling.  
- **CO2:** Apply Maya tools to create 3D animations for characters, including posing and movement.  
- **CO3:** Demonstrate advanced body mechanics and character animation techniques for complex movements like combat and dialogue delivery.  
- **CO4:** Create a complete animated story from concept to final presentation using the principles learned in this course.

### Assessment Strategy  
The course is assessed through the following components:  

| Type of Evaluation          | % Contribution in Grade |
|-------------------------------|------------------------|
| Class Participation           | 5%                     |
| Assignments                  | 30%                    |
| Mid-Semester Examination     | 15%                    |
| End-Semester Examination    | 35%                    |
| Final Project (Group/Individual) | 15%                   |

**Explanation:**  
- **Class Participation:** Active involvement in discussions, group activities, and peer reviews is essential for this course.  
- **Assignments:** Regular assignments are designed to reinforce concepts learned in class, such as character posing, animation sequences, and lighting techniques.  
- **Mid-Semester Examination:** Covers the first half of the course material, focusing on foundational animation principles.  
- **End-Semester Examination:** Comprehensive assessment of all topics covered during the semester.  
- **Final Project:** Students will create a complete animated story using Maya software, demonstrating their ability to integrate all learned techniques into a cohesive project.
