### Course Overview  
**Course Code:** DES519  
**Course Name:** Design of Interactive Systems  
**Credits:** 4  
**Course Offered To:** Undergraduate/Postgraduate (UG/PG)  
**Course Description:** This course is designed to provide students with a comprehensive understanding of the principles and practices involved in designing interactive systems. These systems are integral to our daily lives, including web applications, social media platforms, multimedia applications, and embedded devices. By the end of this course, students will be able to:  
- Understand the foundational concepts of interactive system design.  
- Learn effective techniques for task analysis and user analysis.  
- Evaluate innovative features in existing systems and improve their usability and functionality.

**Course Outcomes (COs):**  
1. **CO1:** To explain the foundation of designing interactive systems.  
2. **CO2:** To discuss techniques for task analysis and user analysis.  
3. **CO3:** To design interaction approaches in different contexts, such as web, social media, and multimedia applications.  
4. **CO4:** To design interaction approaches in different contexts, such as web, social media, and multimedia applications.  
5. **CO5:** To apply core techniques for task analysis and user analysis.  
6. **CO6:** To evaluate innovative features of interactive systems.  
7. **CO7:** To improve the usability and functionality of existing interactive systems.  
8. **CO8:** To critically assess the impact of interactive systems on user experience.

### Assessment Strategy  

| Type of Evaluation         | % Contribution in Grade | Description                                                                                   |
|----------------------------|-------------------------|---------------------------------------------------------------------------------------------|
| Assignment                  | 20%                    | Four individual assignments, each focusing on a major part of the course. Assignments are due every second week. |
| Project                     | 30%                    | A group project involving three students. The project includes three intermediate reports and a final report. Intermediate reports are submitted for sanity checks and feedback. |
| Mid-sem Exam               | 15%                    | Covers syllabus up to Week 4. The exam assesses the foundational concepts of interactive system design. |
| End-sem Examination        | 25%                    | Covers syllabus up to Week 8. The examination evaluates the comprehensive understanding of course topics. |
| Class Participation         | 5%                     | Attendance and participation in class discussions are assessed.                          |
| Paper Presentation          | 5%                     | Group presentation on project progress and final findings.                              |
