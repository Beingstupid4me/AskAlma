**Course Overview**

The course CSE506, titled "Data Mining" is a 4-credit course offered to both undergraduate and postgraduate students. This course provides an in-depth understanding of data mining techniques, which are essential for extracting valuable insights from large datasets. The primary focus of the course is on practical applications, with hands-on experience using tools like R and Weka. Students will learn about various data mining techniques such as classification, clustering, association rule mining, and sequence analysis. These techniques are applied to real-world problems across diverse domains.

**Prerequisites**

To successfully engage with this course, students should have a foundational understanding of the following areas:
- **Programming in Java**: Basic proficiency is recommended.
- **Programming in Python or C++**: While not mandatory, familiarity with programming concepts is advantageous.
- **Mathematics**: A solid background in linear algebra and probability & statistics is required.

**Learning Outcomes**

By the end of this course, students will be able to:
1. **CO1**: Discuss basic applications, concepts, and techniques of data mining, such as association rules mining, classification, clustering, and sequence mining.
2. **CO2**: Use data mining software (e.g., Weka, R) to solve practical problems related to the aforementioned techniques.
3. **CO3**: Analyze the performance of different data mining techniques.

**Weekly Syllabus**

The course is divided into 13 weeks, with each week focusing on specific topics and assignments:

- **Weeks 1-3**: Introduction to exploratory data analysis (EDA), frequent pattern mining, partitional clustering (K-Means, EM), and classification using decision trees. Students will complete an introductory programming assignment involving basic pre-processing and analysis using R.
- **Weeks 4-6**: Advanced EDA techniques, dimensionality reduction methods (PCA, SVD, LDA), and frequent pattern mining for high-dimensional datasets. A practical assignment on PCA/SVD application is included.
- **Weeks 7-9**: Probabilistic classification, support vector machines (SVM), kernel SVM, and classifier evaluation. Students will work on a programming assignment to apply different classifiers and evaluate their performance.
- **Weeks 10-13**: Density-based clustering, hierarchical clustering, spectral clustering, and graph mining techniques. A comprehensive programming assignment focusing on hierarchical/density-based clustering is assigned.

**Assessment Strategy**

The course assessment is designed to evaluate both theoretical understanding and practical application skills:
- **Type of Evaluation**: The evaluation includes quizzes, mid-term examination (mid-sem), end-term examination (end-sem), homework/programming assignments, and a project.
- **Weightage**: Each component contributes as follows: Quizzes (25%), Mid-sem (25%), End-sem (10%), Homework/Assignments (10%), and Project (30%).
- **Contribution to Final Grade**: The final grade is a combination of all these evaluations, with the end-sem examination carrying the highest weightage.

**Learning Resources**

The course provides comprehensive learning materials to support student understanding:
- **Textbook**: "Database Mining and Analysis: Fundamental Concepts and Algorithms" by Mohammed J. Zaki, Wagner Meira Jr.
- **Reference Books**: 
  - "Introduction to Data Mining" by Michael Steinbach, Anand Rajaraman, and Jeffrey David Ullman.
  - "Mining of Massive Datasets" by Jeff Ullman, Anand Rajaraman, and Pang-Ning Tan.

These resources are essential for a deeper understanding of the course content. Students are encouraged to refer to these materials for additional insights and practical examples.
