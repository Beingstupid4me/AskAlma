# Course Overview  
**Course Code:** ECE611  
**Course Name:** Memory Design and Test  
**Credits:** 4  
**Offered To:** UG/PG  
**Duration:** [One Semester]  

This course provides an in-depth exploration of memory design principles, focusing on the challenges and innovations involved in designing memory blocks. Students will gain hands-on experience with CAD tools used in VLSI design, culminating in a project that simulates real-world industrial processes. The course covers essential topics such as SRAM cell design, peripheral circuits, cache hierarchy, DRAM and NVM design, and memory test methods like BIST.

# Learning Outcomes  
By the end of this course, students will be able to:  

- **CO1:** Evaluate and design SRAM cells and peripheral circuits.  
- **CO2:** Analyze the impact of memory architecture on power, performance, and area at both chip and system-on-chip (SoC) levels.  
- **CO3:** Understand the role of cache hierarchy in optimizing memory subsystems.  
- **CO4:** Design specific peripheral circuits for DRAM, NVM, and other memory technologies.  
- **CO5:** Implement test strategies, including BIST, for SRAM and embedded memories.
